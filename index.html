About ConnectX

Anonymous guest presence

ConnectX is a guest-based way to share online presence and discover other visitors. This build includes the presence interface and browser preferences.

  • Version: 0.1.0
  • Presence endpoint: /api/presence
  • Storage: browser local storage for guest identity and preferences; presence data depends on the configured backend.

Chat, connection requests, file transfers, and audio calls require additional server endpoints and, for calls, WebRTC signaling and network traversal support. They are not represented as active features in this page.
